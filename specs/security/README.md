# Seguridad

- [threat-model-baseline.md](threat-model-baseline.md): modelo de amenazas de la fundación.
- Specs o revisiones de seguridad: `SPEC-NNNN-<slug>.md` desde [`_templates/security-review.md`](../_templates/security-review.md).

Toda spec de funcionalidad incluye su sección de seguridad; se crea una spec aquí cuando el cambio es
exclusivamente de seguridad (p. ej. rotación de credenciales, nuevo control) o cuando la revisión lo requiere.
