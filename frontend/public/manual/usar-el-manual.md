# Consultar este manual

El manual describe los procesos de ITMas y se actualiza cada vez que se añade o cambia una funcionalidad. Es
**público**: se puede consultar sin iniciar sesión.

**Quién puede hacerlo:** cualquier persona.

## Pasos

1. Abre **Manual de uso**: desde la página de inicio de sesión ("Consultar el manual de uso"), desde el menú lateral
   de ITMas o con el botón de ayuda de la barra superior.
2. Escribe en **Buscar en el manual** una palabra, por ejemplo "equipo" o "política". No importan las mayúsculas ni
   las tildes.
3. Pulsa un proceso para abrirlo. Cada proceso indica qué permiso necesita, cuándo se actualizó y de qué
   funcionalidad procede.
4. Para compartir un proceso, copia la dirección del navegador: el enlace abre directamente esa página.
5. Para imprimirlo o guardarlo en PDF, usa la opción **Imprimir** del navegador.

## Problemas frecuentes

| Situación | Qué hacer |
|---|---|
| "Este proceso no existe o se ha retirado del manual" | El enlace es antiguo. Vuelve al índice y búscalo por su nombre. |
| El manual describe algo distinto de lo que veo | Avisa al área de TI: el manual debe cambiar a la vez que la aplicación. |
