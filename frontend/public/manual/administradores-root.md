# Administradores Root

Un usuario **Root** tiene acceso irrestricto a todo ITMas, sin necesidad de políticas. Es el nivel reservado a quienes
administran el sistema.

**Quién puede hacerlo:** solo un usuario Root puede conceder o revocar Root.

## Conceder o revocar Root

1. Abre **Administración → Usuarios** y pulsa el usuario.
2. Pulsa **Conceder Root** (o **Revocar Root**) y confirma.

## Reglas

- Siempre debe quedar al menos un Root activo: no se puede revocar ni desactivar al último.
- El primer Root de una instalación lo configura el área de TI.
- Todas estas operaciones quedan en la auditoría.

## Problemas frecuentes

| Situación | Qué hacer |
|---|---|
| No veo el botón Conceder Root | Solo lo ven los usuarios Root. |
| El botón está desactivado | No se puede conceder Root a un usuario inactivo: actívalo antes. |
